# Non-Steam Game Directory

A collection of game builds made by intricos777-dot.
All are free, open-source, and free to modify.
None require Steam to play — they run standalone.

## How to Play

1. Clone the repo
2. Build with `cmake --build build`
3. Run the game binary (usually `build/<game-name>` or `build/test-*`)

For more details, see each game's README.md in its repo.
